# 三瑞微创医疗 AI 配送调度

React + Leaflet 风格地图的医疗器械耗材配送调度作品集项目。

## 启动

```bash
npm install
npm run dev
```

已包含：FEFO 库存批次展示与临期标记、医院客户、订单总重、AI 调度入口、配送看板、loading 提示、localStorage 持久化。

## 1 分钟演示脚本

首次查看演示数据时，如浏览器已有旧数据，可在开发者工具执行 `localStorage.removeItem('sanrui-medical-dispatch-data')` 后刷新页面。系统会载入 8 家医院、3 台车辆和 8 笔待调度订单。

1. 打开“耗材库存”，确认 SR20261001、SR20261115 等临期批次已经标红。
2. 进入“订单创建”，选择一次性穿刺器并填写数量；提交后观察更早有效期批次优先扣减。
3. 进入“调度工作台”，点击“一键重算 VRPTW”，查看每台车医院顺序、ETA、装载率和总里程。
4. 观察 Leaflet 地图上的不同颜色路线，悬浮医院点位查看医院与订单信息。
5. 将订单拖拽到另一台车，再次点击“一键重算 VRPTW”，确认表格与路线更新。
6. 将某笔订单数量提高到超过车辆容量，点击重算，确认出现“无可行解”提示。
